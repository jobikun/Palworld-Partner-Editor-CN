帕鲁伙伴编辑器 v1.6.1 测试说明

一、崩溃修复
- 每次实时写入前重新校验玩家对象、伙伴对象、背包槽位及其当前所有权。
- 玩家对象因传送、切换世界或重建而变化时，实时功能自动断开，不再继续写旧地址。
- 世界参数指针捕获后立即恢复入口指令，不再让捕获跳转常驻游戏过程。
- 伙伴技能冷却和经验钩子完整保存、恢复 EFLAGS，避免改变原游戏条件判断。
- 关闭功能时先重试恢复入口补丁；游戏仍运行期间不释放远程代码页，避免线程已经取到跳转后发生悬空执行。

二、功能与界面
- 带参数功能开启后锁定数值框，必须先关闭开关才可修改。
- “建筑无需材料”改为在建造数据复制时清零 Material1～Material4 数量。
- 批量伙伴操作、实验伙伴和保存不再重复弹确认框，结果统一显示在底部状态栏。
- 保存会自动应用当前伙伴界面数值；未保存修改将被丢弃时仍保留确认。

三、自动检查
- Python 源码编译检查。
- 25 项单元/回归测试。
- PyInstaller Windows 独立 EXE 构建。
- GitHub Actions 自动生成 ZIP、SHA256 和 GitHub Release。

帕鲁伙伴编辑器 v1.6.0 测试说明

一、伙伴存档编辑
- 保留 v1.5.1 的逐只伙伴属性、工作适应性、词条、满级、批量拉满、补齐图鉴和实验伙伴功能。
- 保存仍使用自动备份、临时写入、回读验证和原子替换。

二、独立实时修改器
- 实时窗口从“工具 → 独立实时修改器（48 项）”打开，不改变原伙伴编辑界面。
- 48 项功能契约、中文名称、默认值和快捷键均有自动测试。
- 当前适配目标：
  Palworld-Win64-Shipping.exe
  文件大小：161348096 字节
  SHA256：2FF94A03BC777661BE100249B4940242F70661D890C6B8F8ACA4D6DCE79EE5A5
- 连接时动态解析 UE5.1 的 GUObjectArray、FNamePool、类、属性和当前本地玩家。
- 启用任何实时功能前检查世界的 bIsMultiplay；多人/服务器世界拒绝连接。
- 关闭功能和断开连接会恢复已保存的原始代码及临时参数。
- 未找到经过验证的补丁位置时明确报错，不把无效开关当成成功。
- 当前 Steam 1.0 单人世界实机连接显示 48/48；玩家自己的 5 只队伍伙伴与附近野生 AI 分开处理。
- 11 类机器码功能共 13 个补丁点均完成开启/关闭字节回环验证；隐身、无敌、防护、
  体力、锁血和游戏速度完成运行值及断开恢复验证，游戏进程保持正常。

三、自动检查
- Python 源码编译检查。
- 23 项单元/回归测试。
- PyInstaller 独立 EXE 构建。
- GitHub Actions 自动生成 ZIP、SHA256 和 GitHub Release。

重要：
- 实时修改仅用于本机 Steam 1.0 x64 单人存档。
- 游戏更新导致 SHA256 变化后，必须重新适配，旧版会主动拒绝写入。

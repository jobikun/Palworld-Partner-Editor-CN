# 帕鲁伙伴编辑器

面向 Steam 版 Palworld 1.0 的本地中文伙伴存档编辑器。

## 下载

无需 Python 的 Windows 独立版请从 GitHub 仓库右侧的 **Releases** 下载。
源码构建方法见 `BUILD.md`。

## 自动打包发布

1. 修改源码。
2. 同步修改 `app.py` 中的 `APP_VERSION`。
3. 使用 GitHub Desktop 提交并推送到 `main`。
4. GitHub Actions 会自动检查源码、构建 Windows EXE、生成 ZIP 和 SHA256，并创建对应版本的 Release。

若对应版本标签已经存在，自动流程会停止，避免覆盖已经发布的版本。

## 功能

- 自动定位最近使用的 `Level.sav`
- 按 Steam 玩家列出背包和终端中的伙伴
- 修改生命 IV、近战/远程攻击 IV
- 修改生命、攻击、防御 IV/灵魂强化以及工作速度强化
- 逐只编辑最多 4 个被动词条，支持中文名、内部 ID 和效果说明搜索
- 多种顶级词条预设，包括神仙全能、神仙战神、战斗、手工、制药、采矿、飞行、陆地、水上、骑乘续航和配种等
- 通过“工具”菜单将所选预设或当前四词条一键应用到当前玩家的全部伙伴
- 当前伙伴一键 Lv.80，或将当前玩家的全部伙伴一键 Lv.80
- 超限模式支持 IV/灵魂强化 0～255、浓缩等级 0～254
- 可将当前玩家的全部伙伴一键设为 Lv.80 和超限战斗最大值，并将各自已有工作设为 10
- 一键补齐当前玩家尚未拥有的全部正常可获得物种/亚种，每种一只并放入帕鲁终端
- 使用 Palworld 1.0 数据表显示 299 个物种的简体中文名称
- 只显示该物种实际拥有的工作适应性，并可设置最终等级 1～10
- 识别异常浓缩 `Rank`，不再把 127 等原始值误显示为 126 星
- 保存前检查游戏进程和存档外部变更
- 自动备份、临时写入、回读验证、原子替换
- 新增伙伴时同时验证实体、终端槽位和公会成员记录；1.0 新增的公会尾部数据原样保留
- “工具”菜单提供高风险的实验枯星龙生成；采用事务式写入，不会在构造失败时留下孤立终端槽位
- 保持原浅色伙伴编辑界面，并为右侧编辑区域增加垂直滚动条
- 在同一个主窗口内通过“伙伴编辑器 / 实时修改器（48 项）”两个页面切换

## 实时修改器（48 项）

主窗口顶部可直接切换“伙伴编辑器”和“实时修改器（48 项）”，不再打开第二个窗口。

使用时先进入本地单人世界，再点击“连接当前单人世界”。程序会校验当前
`Palworld-Win64-Shipping.exe` 的完整 SHA256，动态解析 UE5 对象和属性偏移，
并在功能关闭、断开连接或主程序退出时恢复临时代码补丁和速度/世界参数。
带数值的功能启用后会锁定参数框；需要修改参数时，先关闭对应开关。

窗口按原 48 项快捷键排列，包含玩家战斗、捕捉/掉落、背包、制造/建造、时间、
伙伴、武器、经验/点数、速度/移动和玩家属性上限。没有找到经过验证的现版本补丁时，
程序会明确报错，不会把无效开关显示成成功。
伙伴生命、饱腹、SAN 和体力作用于当前玩家拥有的全部伙伴，包括队伍、基地和帕鲁终端；“AI 速度”仍单独作用于
当前世界已加载的 AI，不会把附近野怪误当成玩家伙伴锁血。
“建筑无需材料”直接清零游戏交给建造系统的四项材料数量，不再使用旧版无效的条件跳转。
“武器瞬间冷却”同时处理通用武器冷却、过热步枪和光束发射器的独立热量与过热状态。
“玩家移动速度倍率”同时调整步行、冲刺、蹲行、游泳、飞行、攀爬、滑行和对应加速度；
“玩家动作速度倍率”则调整角色自身的时间倍率，两者用途不同。
伙伴列表会排除警卫、人类 NPC 和奖励占位对象，批量操作不会写入这些非伙伴条目。

实时修改器只允许已适配的 Steam 1.0 x64 本地单人世界；检测到多人/服务器世界会
在启用任何功能前拒绝连接。游戏更新后若程序指纹变化，也会拒绝写入并要求重新适配。

## 安全提示

必须先正常退出 Palworld 再保存。备份保存在世界存档目录的
`PalPartnerEditor_Backups` 文件夹中。

实验枯星龙没有完整的伙伴技能、骑乘和正常技能表，可能无法正常出战或导致游戏异常。
生成前务必保留自动备份。

本项目复用了 PalEdit 的 MIT 许可数据解析代码。许可证见
`THIRD_PARTY_PALEDIT_LICENSE.txt`。

Palworld 1.0 物种名称和工作适应性数据来自 Pal Calc v1.17.7（数据库 v26），
其 MIT 许可证见 `THIRD_PARTY_PALCALC_LICENSE.txt`。
